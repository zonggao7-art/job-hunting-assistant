# 求职辅助工具包 · Job Hunting Assistant

一套面向**中文求职场景**（Boss直聘为主）的求职辅助工具，核心是一个浏览器侧边栏扩展，形态类似 Edge 的 Copilot：你在刷岗位，点一下按钮，侧边栏直接给出岗位分析、简历修改建议和回复草稿。

所有分析都在你自己的浏览器里发起，不经过本项目自建服务器。API Key 和简历只存在本机；点击分析后，必要的页面内容会发送给你选择的模型供应商。

## 它能做什么

**岗位分析（五件套）**：在任意 Boss直聘岗位详情页点一下，输出

1. 拆解卡：硬门槛逐条核对、岗位真面目（实际在做什么）、隐性信号、红旗
2. 匹配结论：冲 / 稳 / 弃 三档 + 匹配点 + 真实缺口 + 反向评估（这岗位配不配得上你）
3. 简历修改点：可执行到「哪一块加什么句子」，且明确「不用改的」
4. Boss直聘打招呼开场白：可直接复制的短消息
5. 面试题预测：按概率排序，附答法要点

**回复助手**：在 HR 聊天页点一下，抓取当前对话，生成 HR 意图判断 + 三版回复草稿（推进型 / 稳缓型）+ 建议你反问的问题。**只起草，绝不自动发送**，发送权始终在你手里。技术类问题只给答题要点框架，不代你作答。

**简历上传**：支持 PDF / Word(.docx) / txt / md。解析出的文字可编辑、可保存，之后所有分析都以你的简历为准；也可以让模型把你的简历原文提炼成结构化画像。PDF 解析库已内置，无需额外安装。

**多模型供应商**：内置智谱 GLM（免费）、DeepSeek、通义千问、Kimi、硅基流动预设，也可填任意 OpenAI 兼容的自定义地址。文本模型和视觉模型分开配置，切换不需要改代码。

**岗位采集器（可选）**：基于 DrissionPage 的旁观式采集脚本，自动把你浏览过的岗位 JD 存到本地（图片 + 文本 + 元信息），解决 Boss直聘 JD 无法复制文字的问题。

**Claude Skill（可选）**：`skill/jd-analysis/` 是纯提示词版的分析流程，可直接放进 Claude 的 skills 目录使用，不依赖扩展。首次使用时请提供自己的简历画像；没有宿主记忆文件时，skill 会先向你索要必要经历，不会使用仓库里的示例画像。

## 快速开始

### 1. 拿到免费的模型 API Key

推荐智谱（Glm）：打开 [open.bigmodel.cn](https://open.bigmodel.cn) → 注册 → 控制台 → API Keys → 创建并复制。`glm-4-flash` 和 `glm-4v-flash` 都是免费模型，日常用不花钱。

想用别的供应商也可以，扩展里内置了预设：DeepSeek（按量计费，很便宜）、通义千问、Kimi、硅基流动，或任何 OpenAI 兼容地址。

### 2. 安装浏览器扩展

1. Edge 地址栏输入 `edge://extensions`（Chrome 是 `chrome://extensions`）
2. 打开「开发人员模式」
3. 点「加载解压缩的扩展」，选择本仓库的 `extension` 文件夹
4. 建议把图标钉到工具栏

### 3. 配置

点扩展图标打开侧边栏 → 「设置」标签

- 模型：选供应商 → 填入 API Key → 点「保存设置」→ 点「测试连通」确认配置正确
- 简历：点「上传简历文件」选你的简历（PDF / Word / txt 都行）→ 确认文字没问题 → 点「保存简历」

### 4. 用起来

- 岗位页：点「分析当前岗位页」→ 等 10~30 秒 → 五件套出现，可一键复制
- 聊天页：点「抓取对话并生成回复」→ 出三版草稿

## 目录结构

```
extension/       浏览器侧边栏扩展（MV3，Edge / Chrome）
  sidepanel.js     抓取逻辑 + 提示词 + 模型调用
  sidepanel.html   侧边栏界面
  pdf.min.js       PDF 解析库（pdf.js，已内置）
collector/       岗位 JD 采集器（Python + DrissionPage）
skill/            Claude Skill：纯提示词版的分析流程
```

## 模型供应商对照

| 供应商 | 文本模型（默认） | 视觉模型（截图兜底） | 说明 |
|---|---|---|---|
| 智谱 GLM | glm-4-flash | glm-4v-flash | 两个都免费，开箱推荐 |
| DeepSeek | deepseek-chat | 无 | 按量计费，文本质量好，无视觉 |
| 通义千问 | qwen-plus | qwen-vl-plus | 阿里云百炼开通 DashScope |
| Kimi | moonshot-v1-8k | 无 | 长上下文，无视觉 |
| 硅基流动 | DeepSeek-V3 | Qwen2.5-VL-7B | 部分模型免费 |
| 自定义 | 任意 | 任意 | 填 OpenAI 兼容地址，保存时会申请该域名权限 |

视觉模型只在「页面文本抓不到、自动改用截图识别」时使用，可以留空。

## 隐私说明

- API Key、简历内容只存在浏览器本地存储（`chrome.storage.local`），不会上传到除你选择的模型供应商之外的任何地方
- 只有你点击按钮那一刻的页面内容（JD 文本 / 对话文本 / 截图）会发送给你配置的模型 API
- 扩展不后台监听、不主动抓取、不采集浏览记录
- 采集器只读取你自己已登录的浏览器页面（通过调试端口连接本地浏览器），不绕过登录、不自动投递、不自动发送消息
- 采集器默认把数据写到用户桌面的 `boss_jobs`，Chrome 登录态写到桌面的 `boss_jd_tool/chrome_profile`；可用 `BOSS_JOBS_DIR`、`BOSS_CHROME_PROFILE_DIR` 环境变量改目录。它们已加入 `.gitignore`，不要把个人数据提交到仓库

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示「请先到设置标签配置模型」 | 到「设置」填好供应商、API Key、模型名，点「保存设置」 |
| API 401 / 403 | Key 复制错了或权限不足，重新粘贴后点「存」；可先用「测试连通」验证 |
| 岗位分析结果截断 | 点「复制结果」拿全文，或重试一次 |
| 聊天抓取失败 | 把对话滚动到屏幕内再点一次；仍失败可点「诊断」按钮导出结构信息提 issue |
| 简历上传提示解析失败 | 扫描件（图片版 PDF）提不出文字，请改用文本版简历或直接粘贴文字 |
| 改了简历但分析没变化 | 修改后必须点「保存简历」才生效 |

## 发布到 GitHub（仓库作者用）

先在 GitHub 网页上新建一个**空仓库**（不要勾选 README / .gitignore / License），然后在本地执行：

```bash
cd job-hunting-assistant
git init
git add -A
git commit -m "Initial commit: 求职辅助工具包"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

Windows 上也可以直接双击 `一键推送.bat`，按提示粘贴仓库地址即可。没装 Git 的话，用 GitHub 网页的「Add file → Upload files」把文件夹拖上去也可以（注意保持目录结构）。

推送前请确认左下几项都没被带上去：`collector/chrome_profile/`（含浏览器登录态）、`collector/boss_jobs/`（你的采集数据）、任何简历文件。`.gitignore` 已经默认排除这些。
