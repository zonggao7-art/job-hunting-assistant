# Boss直聘 JD 采集器 · 使用说明

## 这是什么

一个"旁观式"采集器：接管一个专门的 Chrome 窗口，你在里面**正常刷岗位**，
每打开一个岗位详情页，它自动把 JD 截图 + OCR 成文字，默认存到用户桌面的 `boss_jobs\`，
攒了一批之后丢给 Claude 一次性分析，再也不用手动一张张截屏。

它**不会**自动浏览、不会自动打招呼、不会碰你日常用的 Chrome，只读你打开过的页面。

## 首次配置（只做一次）

1. 确认电脑装了 Python 3.9+（没有就去 python.org 下载，安装时勾选 "Add Python to PATH"）
2. 确认电脑装了 Chrome 浏览器
3. 双击 `0_安装依赖.bat`，等它说"安装完成"

## 日常使用（每次找工作时）

1. 双击 `1_开始采集.bat` → 自动弹出一个 Chrome 窗口
2. 第一次会需要在这个窗口里登录 Boss直聘（之后登录状态会记住，不用再登）
3. 像平常一样搜索、点开岗位——你每打开一个详情页，桌面 `boss_jobs` 里就会多一个文件夹
4. 刷完一批后，回 Claude 对话说一句"**分析新采集的岗位**"，我会读取文件夹、逐个出五件套分析并按匹配度排序

## 存档结构

```
桌面\boss_jobs\
  └─ 1005_1930_<岗位ID>\
       jd.png      JD 区域截图
       jd.md       OCR 文本 + 薪资/公司/链接元数据
       info.json   原始信息
```

同一个岗位只存一次（去重）。OCR 失败也没关系，jd.png 在，直接给 Claude 读图。

## 风控注意事项（重要）

- 脚本只是"看你手动打开的页面"，这和用眼睛看没区别，风险很低；但请保持克制：
- 不要挂机跑一整夜、不要用任何自动翻页工具配合它
- 如果弹出了滑块验证码，先停下刷岗位，等一会儿再继续
- 采集到的数据只存你自己电脑本地

## 常见问题

| 现象 | 处理 |
|---|---|
| "无法启动 Chrome" | 确认装了 Chrome；把桌面下的 `boss_jd_tool\chrome_profile` 文件夹删掉重试 |
| 弹出的 Chrome 里登录态丢了 | 正常，首次需要在采集窗口里登录一次 |
| 岗位存了但 jd.md 里文字是空的 | OCR 没跑起来，`0_安装依赖.bat` 重装一次；或直接用 jd.png |
| Boss 改版导致抓不到标题/薪资 | 截图仍然有效，Claude 可以直接从图里读，分析不受影响 |
| 想清空重新来 | 删掉 `boss_jobs` 文件夹即可 |

默认目录也可以通过环境变量覆盖：

- `BOSS_JOBS_DIR`：岗位数据和状态文件
- `BOSS_CHROME_PROFILE_DIR`：采集器使用的 Chrome 配置目录
- `BOSS_DESKTOP_DIR`：同时修改以上两个默认目录的桌面根目录
