# JD 岗位分析 · 浏览器侧边栏扩展 安装说明

## 它是什么

一个 Edge/Chrome 侧边栏插件，形态和 Copilot 一样：你在 Boss直聘刷岗位，
点一下按钮，侧边栏直接输出五件套分析（拆解卡/匹配结论/简历修改点/开场白/面试题）。
分析用的是你在「设置」里保存的简历，与本仓库 `skill/jd-analysis` 同一套逻辑。

## 安装步骤（只做一次）

1. **拿智谱 API Key**（免费）：打开 https://open.bigmodel.cn → 注册/登录 →
   控制台 → 「API Keys」→ 创建并复制。glm-4-flash 和 glm-4v-flash 都是免费模型，不产生费用。
2. **加载扩展**：Edge 地址栏输入 `edge://extensions`（Chrome 是 `chrome://extensions`）→
   打开左下角/右上角「开发人员模式」→ 点「加载解压缩的扩展」→
   选择本仓库里的 `extension` 文件夹。
3. **固定图标**（可选）：工具栏拼图图标 → 把「JD岗位分析助手」钉住。

## 日常使用

1. 打开 Boss直聘任意岗位详情页
2. 点工具栏扩展图标 → 右侧弹出侧边栏
3. 第一次：默认就是智谱免费模型。到「设置」标签填一次智谱 API Key → 点「保存设置」（只存本机，之后不用再填）。
   想换模型：设置里选 DeepSeek / 通义千问 / Kimi / 硅基流动 预设并填对应 Key；「测试连通」按钮可当场验证配置对不对
4. 「岗位分析」标签：点「分析当前岗位页」→ 等 10-30 秒 → 五件套出现 → 可一键复制
5. 「回复助手」标签：打开和 HR 的聊天页 → 点「抓取对话并生成回复」→ 出三版草稿 + 反问建议

## 回复助手说明

- 只生成草稿，**发送权永远在你手里**，扩展绝不自动发送
- 抓取主路线是**结构级精确抓取**：已把左侧会话列表从数据源整棵剔除（曾导致抓错人的根源），称呼只认聊天面板顶部标题；文本抓不到时自动退回截屏+视觉模型
- 三版草稿：推进型（直接约下一步）/ 稳缓型（先答问题留伏笔）；技术问题额外给"答题要点框架"而非成品答案——技术缺口要自己补，别让 AI 替你面试
- 会自动关联你分析过的岗位 JD（需先在岗位页跑过「分析」），匹配不到就退化为纯对话上下文
- 若对话超出屏幕可视范围，把页面滚动到想让我看到的部分再点一次（截图只读当前画面）

## 上传简历（v1.6）

「设置」标签最下方是简历区，用来换掉内置的简历画像——你简历更新后不用再找我改代码。

- **上传简历文件**：支持 PDF / Word(.docx) / txt / md。解析出的文字会显示在下面的大框里，可以直接修改，点「保存简历」后所有分析都以它为准
- **AI 提炼成画像**：简历文字比较乱时，点一下让模型整理成结构化画像（保留数字、不编造），再保存
- **恢复默认**：退回内置画像

### 关于 PDF

PDF 解析库（pdf.js 3.11.174 的 `pdf.min.js` + `pdf.worker.min.js`，约 1.4MB）已经内置在扩展文件夹里，**不需要你做任何事**——上传 PDF 直接可用。这两个文件不要删除，删了 PDF 上传会失效（txt / Word 不受影响）。

解析逻辑做了「按视觉坐标重排」：PDF 内部文字流顺序常常不等于阅读顺序（简历常用文本框排版），所以先按纵坐标分行、行内按横坐标排序，并只在字块之间真有间隙时才补空格。实测你的简历 PDF：1891 字全部提取，68.00% / 94.25% / 30.0%→97.0% 等数字保真，无断字。

扫描件（图片版 PDF）提取不出文字，会明确提示——这种只能用带 OCR 的工具或直接粘贴文字。

## 换模型 / 换供应商

- 「设置」标签：选供应商预设（智谱 / DeepSeek / 通义千问 / Kimi / 硅基流动 / 自定义），地址和模型名会自动填好，你只需填 Key
- 文本模型干分析+草稿；视觉模型只用于截图兜底，可留空（DeepSeek/Kimi 暂无视觉模型，留空时截图兜底会明确提示跳过）
- 生成时状态栏会显示当前用的「供应商 · 模型名」，用了什么一目了然
- 自定义中转站：API 地址填 OpenAI 兼容的 Base URL，保存时扩展会弹窗申请该域名访问权限
- 配置只存本机浏览器，切换不需要重新装扩展

## 注意

- 岗位页要「点开详情」的那种页面（网址含 job_detail），列表页没法分析单个岗位
- 扩展只在你点击按钮那一刻读取当前页，不会后台监听、不上传任何数据（只有 JD 内容发到智谱 API 做分析）
- Boss 改版可能导致抓取失败，届时可点侧边栏的「诊断」按钮导出结构信息并提 issue

## 常见问题

| 现象 | 处理 |
|---|---|
| API 401 | Key 复制错了，重新粘贴后点「存」 |
| 分析结果截断 | 点「复制结果」拿到全部；或重试一次 |
| "抓取不足"一直出现 | 正常会走截屏兜底；若截屏也失败，确认页面非企业版登录墙 |
| 扩展点开没反应 | 到 edge://extensions 看有没有红色报错，带上信息提 issue |
